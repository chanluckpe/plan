# 급식대장의 작전 만들기

체육 수업과 팀 훈련을 위한 작전판 웹앱입니다. 학생과 선수가 직접 작전을 그리고, 「작전 보기」로 움직임을 돌려 보고, 작전집으로 모아 저장할 수 있어요.

- **바로 쓰기:** `index.html` 하나만 브라우저로 열면 됩니다. (GitHub Pages로 배포해도 바로 동작해요.)
- **종목 (19개):** 플래그풋볼 · 농구 · 배구 · 티볼 · 축구 · 플라잉디스크 · 피구 · 넷볼 · 풋살 · 핸드볼 · 플로어볼 · 킨볼 · 라크로스 · 럭비 · 추크볼 · 라켓 스포츠(배드민턴 · 탁구 · 피클볼 · 테니스 복식)
- **기기:** 웹(컴퓨터), 태블릿, 휴대폰 (휴대폰·태블릿은 전체화면 작전판)

## 주요 기능

- 🤖 **자동 선 종류** — 선수를 끌기만 하면 패스 · 슛 · 드리블 · 달리기를 알아서 정하고, 패스 타이밍도 자동으로 맞춰요.
- ▶ **작전 보기** — 종목별 규칙(오프사이드, 트래블링, 3초 룰, 스로 포워드, 투 바운스 등)을 반영한 시뮬레이션
- 📒 **작전집** — 작전 모아 보기, 이미지(PNG)·PDF 저장(작전 수에 맞춘 배치), A4 인쇄, 작전 파일(JSON) 내보내기·불러오기
- 📌 **종목 포인트** — 종목마다 꼭 알아야 할 규칙과 팁
- 🎵 **배경음** — 시작 화면을 누르면 재생, 하단 「음악」 버튼으로 켜고 끄기 (`src/bgm.mp3`)

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 앱 (한 파일, 바로 실행) |
| `src/` | 원본 코드 — 엔진(`engine.js`), 종목 정의(`sports1~7.js`), 화면(`app.js`, `fs.js`, `motion.js`, `bgm.js`), 스타일, 그림 |
| `build.py` | `src/`를 한 파일로 묶어 `dist/artifact.html`을 만들어요 |
| `tools/` | 종목 카드 캐릭터 그림을 자르고 배경을 빼는 스크립트 |
| `test/` | 예시 작전 시뮬레이션 점검(`simtest.js`)과 화면 테스트(Playwright) |
| `preview/shell.html` | 휴대폰·태블릿 화면을 한 번에 보는 미리보기 틀 |

## 다시 만들기

```bash
mkdir -p dist
python3 build.py          # dist/artifact.html 생성
cp dist/artifact.html index.html
node test/simtest.js      # 모든 예시 작전 결과 확인
```
